# キックドラムのアナログ回路を読む

本で紹介した回路学習アプリです。現在は **0章「回路の全体像」** を読めます。1〜6章の解説、部品値を変えて波形を比較する実験、全体回路のシミュレーションは公開予定です。

## 開き方

1. [アプリをZIPでダウンロード](https://github.com/kazeruch/kick-drum-circuit-lab/archive/refs/heads/main.zip)します。
2. ZIPを展開し、フォルダーの一番上にある `index.html` をブラウザーで開きます。インストールやサーバーの起動は不要です。

## 回路図の読み方

最初に、図の左下の入力端子 **GATE IN** と、右下の出力端子 **OUTPUT** を探してみてください。説明欄の「0.2へ」から先へ進むと、一打の入力がどこで振動に変わり、どの配線を通って出力に届くかを順にたどれます。

部品や端子が見つけづらいときは、本文の下線を押すと図の該当箇所を拡大できます。図の番号付きの範囲名を押すと、その範囲を拡大します。「全体表示」で図全体に戻れます。

回路図のもとにしたマニュアルは[出典](./NOTICE.md)に記載しています。
